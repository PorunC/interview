# 英文面试材料

英文材料只用于练表达，项目事实仍以中文专项主文档为准。建议先把中文答案讲顺，再把同一条“结论、链路、取舍、结果、边界”转换成英文，不要为追求流利度新增未经验证的技术细节。

## 文件说明

- [三项目与 Agent 系统设计](./三项目与Agent系统设计-英文.md)：三个项目、自我介绍和 Agent 系统设计的综合英文话术。
- [Agent Memory 端到端系统深挖](./Agent-Memory-端到端系统深挖-英文.md)：长期记忆、Hybrid RRF、调度、上下文卸载和恢复链路。
- [Agent Memory 专项面试深挖](./Agent-Memory-专项面试深挖-英文.md)：生产化、评估、故障案例，以及记忆表征、Context Engineering、LoRA 和 Markdown Memory 高频英文追问。
- [英文 Live Coding 与系统设计表达](./英文Live-Coding与系统设计表达.md)：完整现场表达框架、20 道算法/并发/API 英文演练、Underwriting/金融投研 Agent/Agent Runtime 三道系统设计，以及被打断、卡住和事实边界话术。
- [英文行为面与 HR 追问口语模板](./英文行为面与HR追问口语模板.md)：40 道求职动机、Ownership、协作、冲突、失败、谈薪和反问题；所有 `[FILL: ...]` 都是待本人用真实证据关闭的事实项。

## 推荐使用顺序

1. 先读“三项目与 Agent 系统设计”的自我介绍、三个项目主回答和 One-Page Cheat Sheet，形成 90 秒、3 分钟和 10 分钟三档表达。
2. Agent Memory 岗位再读“端到端系统深挖”，掌握当前源码链路；随后读“专项面试深挖”的生产化问答和 Part 7 通用记忆概念。
3. 有英文 Coding Round 或 System Design Round 时，再进入 Live Coding 文档按题计时演练。
4. HR 面前用行为面文档关闭所有 `[FILL: ...]`，没有真实证据的数字、事故和 Ownership 不直接背诵。
