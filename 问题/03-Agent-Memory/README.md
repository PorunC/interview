# Agent Memory 面试资料入口

本目录按“项目事实、知识体系、生产治理”三层使用，所有项目均按公司内部项目口径回答，不依据源码日期或仓库信息判断归属。

1. [AI 记忆系统全链路源码级深入分析](./Agent-Memory-全链路源码级深入分析.md)：当前实现事实、104 道源码追问、已确认缺口与下一版设计。
2. [Agent 记忆知识体系与开源项目面试题](./Agent记忆知识体系与开源项目面试题.md)：54 道口语题，覆盖记忆类型、作用域、原始证据、Admission、热/后台写入、冲突、时间、巩固、三种记忆表征、上下文治理和 Markdown Memory。
3. [Agent 记忆生产治理与开源生态面试题](./Agent记忆生产治理与开源生态面试题.md)：75 道口语题，覆盖 Hybrid Recall、遗忘、安全、评测和开源项目选型。

## 推荐顺序

- 面试前快速准备：先读源码级分析的 30 秒总回答、Q1-Q20 和 Q61-Q104，再读开源生态 Q051-Q075。
- 面试官追问“怎么存、怎么取”：读知识体系 Q016-Q047，再读生产治理 Q001-Q020。
- 面试官追问 Token/参数/潜在记忆或 Markdown Memory：读知识体系 Q036-Q054。
- 面试官追问冲突、删除、投毒：读生产治理 Q021-Q040。
- 面试官追问怎么证明效果：读生产治理 Q041-Q050。
- 面试官追问 Mem0、Letta、Zep、LangMem：读生产治理 Q051-Q075 和开源项目速查表。

## 事实边界

- 外部项目 README、官网或论文的 Benchmark 均视为项目方公开口径，不冒充公司内部项目结果。
- 托管平台能力和开源仓库能力必须分开，例如 Mem0 Platform 与 OSS、Zep Cloud 与 Graphiti、旧 Letta V1 与当前 Letta Code。
- 选型结论必须在同一数据集、模型、Token、延迟和部署条件下重跑，不按 Star 数或官网最好分直接排名。
- 外部项目具备的时间图、多租户、硬删除、审批或安全能力，不能反向说成公司内部项目已经实现。
