## ⚠️ 重要前置说明（请首先阅读）

豆沙包**并非纯粹的"跨境电商保险科技公司"**。经多源核实，其业务演进路径为：

- **2016 年成立**，以跨境电商保险起家（自称"全球首家跨境电商保险平台"）
- **2017 年**在中国首创跨境电商保险
- **2019 年**起通过 API 技术与银行合作上线数字金融（贷款/融资）产品，**金融业务逐渐成为主营业务**
- 当前官方对外定位已转为**"全球领先的跨境电商数字 API 平台 / 跨境电商金融科技服务商"**

因此，其官网主站（dowsure.com）以**贷款/融资产品**为主，保险业务保留在独立子站（shield.dowsure.com、dowsure.hk）及亚马逊应用商店中。**评估其市场定位时须注意这一转型。**

## 六、商业模式

豆沙包是**"保险科技平台 + 信贷科技平台"的双重模式**，本质上是**平台/科技赋能方**，而非持牌保险公司或银行：

### 保险业务：保险科技平台 / 保险经纪性质
- 不承保，通过 API 对接多家保险公司出单
- 角色：科技赋能 + 产品设计 + 渠道获客 + 理赔协助
- 收入：保险科技服务费 + 佣金（具体分成未公开）

### 金融业务：信贷科技平台 / 嵌入式金融
- 不直接放款，作为科技平台连接卖家与银行
- 角色：风控模型（DVA™）+ 数据处理（DDM™）+ 资金闭环管控（DAL™）+ 流量入口
- 收入：科技服务费 / 信贷推荐服务费（具体未公开）
- 核心逻辑：**用保险为信贷增信**，形成"保险+信贷"闭环

### 归属判断
- **不是保险公司**（无承保资质）
- **具有保险经纪/科技属性**
- **官方定位为"保险科技公司 / 数字 API 平台 / 金融科技服务商"**
- 更准确描述：**跨境电商生态的"数字金融基础设施"提供商**

## 九、市场规模与竞争格局

### 9.1 市场规模

**跨境电商整体市场**（保险的底层需求池）：
- 2024 年中国跨境电商市场规模达 **17.66 万亿元**，同比增长 4.8%（网经社）
- 占我国货物贸易进出口总值的 40.27%；出口占比 77.6%
- 全球电商销售额 2024 年预计 6.3 万亿美元，2027 年预计达 8 万亿美元

**跨境电商保险细分市场**：
- 2023 年跨境保险渗透率约 **18.7%**（艾瑞咨询）
- 约 **67% 的头部跨境卖家已配置至少一项专项保险**，较 2021 年提升 24 个百分点
- 物流险覆盖率最高，达 58.3%；知识产权侵权责任险渗透率仅 12.7%
- 年销售额超 100 万美元的卖家群体中，购买"货运+海外仓"组合险的比例达 43.6%

## 十一、整体判断与面试要点

### 公司状态判断
豆沙包是一家**已走到 C 轮、累计融资约 2.9 亿人民币的跨境电商金融科技公司**，处于**逆周期扩张期**：在宏观贸易波动下仍获汇丰加码，拓展东南亚（越南/新加坡）和沃尔玛渠道，发布 T+0 极速回款产品，国际化与 AI 化是明确方向。核心看点是**与汇丰的深度战略合作**（汇丰连续两轮领投）和**亚马逊官方贷款计划合作伙伴**身份。

### 面试要点提示

1. **能准确说出公司关键事实**：2016 年成立、创始人裴忠方（Byron Pei）、累计融资约 2.9 亿人民币、C1 轮由汇丰领投、运营总部在深圳福田。
2. **理解业务转型**：豆沙包已从纯保险科技转型为"保险+信贷"双业务的金融科技公司，**当前主营是信贷科技**，保险是切入场景和风控手段。这一点很关键，不要只谈保险。
3. **投资方澄清**：是**创业工场（VenturesLab）**，不是"创新工场（Sinovation）"；没有红杉、IDG。汇丰是核心战略投资方。
4. **技术栈**：Java + Spring Cloud 全家桶 + Redis + RabbitMQ，2025 年明显向 **AI（Spring AI / LLM / Agent）** 转型。面试中可主动谈对 AI 在风控/获客场景应用的看法。
5. **核心合作背书**：亚马逊 SPN 金融类目首批合作伙伴 + 沃尔玛亚太首家贷款计划合作伙伴 + 汇丰战略投资 + The Asset Triple A Awards 2024 获奖产品。
6. **关注 AI 方向**：Dowsure AI+ 产品矩阵（AI+Leads/Risk/Shield/Data）是当前产品重心，面试中可主动谈及。
