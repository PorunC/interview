### 创立故事（来自 Forbes 长文记录）

2011 年夏，三人在芝加哥大学公寓做 **JoinStart**（学生众筹平台）失败后，发现"用户想要更简单的建站方式"这一痛点，pivot 到单页建站工具 Strikingly。2012 年 4 月首次申请 YC **被拒**，7 月搬到旧金山，12 月才被 W2013 录取。**产品上线次月即实现盈利**。

## 四、产品与商业模式

### 4.1 核心定位

**移动优先（mobile-first）、零代码零设计**的自助建站 SaaS。

- 国际版口号："Make a website in minutes. Zero code or design skills required."
- 中国版定位："十分钟创建网站和小程序，无需专业技术知识与设计经验。"

### 4.2 核心功能

- **移动优先建站**：所有模板移动端自适应；有手机端编辑器及 iPhone App
- **单页 / 多页**：单页起家，Pro 套餐支持单站最多 100 页
- **可视化编辑器**：单屏编辑，点击即改、即时发布
- **电商 Simple Store**：绑定 PayPal/Stripe 收款，Pro 最多 300 件商品、VIP 500 件
- **会员系统、博客、表单、实时聊天、邮件群发、域名 SSL、数据分析**等

### 4.3 商业模式：Freemium + 订阅制

**国际版定价（美元，年付折算月价）**：

| 套餐 | 月费 | 核心权益 | 交易手续费 |
|------|------|---------|-----------|
| Free | $0 | 子域名、500MB 存储、5GB/月带宽、1 件商品 | **5%** |
| **Pro**（最畅销） | **$16/月** | 3 个 Pro 网站、自定义域名+免费 SSL+赠一年域名、20GB/站、无限带宽、100 页/站、300 件商品、去 logo、会员系统 | **2%** |
| VIP | $49/月 | 5 个 VIP 网站、Pro 全部功能、100GB/站、2000 联系人、500 件商品、多语言翻译、电话客服、专属客户经理 | **0%** |

**中国版（sxl.cn）最大差异化：深度整合微信小程序生态**

- 小程序商城、团购、秒杀、预约支付、会员卡、服务消息
- 超级云名片小程序、微信支付/支付宝本地化支付
- 这是 Wix/Squarespace/Weebly/Webflow/Shopify 均不具备的本地化能力

> 注：sxl.cn 的人民币定价页需登录才能查看，未抓到公开标价。

### 4.4 AI 建站（最新趋势，重要）

| 产品 | 国际版 | 中国版 |
|------|--------|--------|
| **AI Site Builder**（输入业务描述自动生成整站） | ✅ 已上线（约 2024 末–2025 年初） | ❌ 未开放（配置开关为 false） |
| **AI Logo Maker / 标小智**（logosc.cn） | ✅ | ✅（已生成超 251 万个 logo） |

## 五、技术栈（来源：GitHub strikingly 组织 + 官方荣誉推断）

| 层 | 技术 | 证据 |
|----|------|------|
| **后端** | **Ruby on Rails** | `hypernova-ruby`、`ckeditor`（Rails gem） |
| **前端** | **React** | `moreartyjs`、`react-i18n`、`react-templates` |
| **服务端渲染** | **Hypernova**（Airbnb 开源，SSR React） | `hypernova-ruby` |
| **边缘/网关** | **OpenResty + Lua** | `lua-resty-repl` |
| **Node.js 生态** | Node.js | `cloudinary_npm` |
| **云服务** | **AWS（海外）+ 阿里云（国内）双云** | CTO 同时为阿里云 MVP（4年）与 AWS Hero |
| **图片/CDN** | Cloudinary；自有 CDN（sxlcdn.com、strikinglycdn.com） | 仓库 + 页面资源域名 |
| **支付** | PayPal、Stripe | 官网 |

> 说明：数据库等具体细节因招聘 JD 需登录无法获取，未列出。面试时如被问技术栈，Rails + React + Hypernova 是较可靠的回答。

## 七、竞争格局对比

| 维度 | Strikingly | Wix | Squarespace | Weebly | Webflow | Shopify |
|------|-----------|-----|-------------|--------|---------|---------|
| 起家特色 | **单页式、移动优先、单屏编辑** | 拖拽编辑、ADI/AI | 设计感强 | 极简易用 | 专业级可视化 | 纯电商 |
| 上手难度 | 极低（30 分钟） | 低 | 低-中 | 极低 | 高 | 中 |
| AI 建站 | ✅ 已上线 | ✅ | ✅ | 较弱 | 无原生 | 内容 AI |
| 价格 | $0/$16/$49 | $17-35+ | $16-65 | 免费起步 | $14-39+ | $29+ |
| **中国本土化** | **微信小程序生态（独有）** | 无 | 无 | 无 | 无 | 无 |

**Strikingly 差异化要点**：① 移动优先+单屏编辑的极简体验 ② 低门槛 Freemium ③ 中国版微信小程序深度整合 ④ 面向无技术背景用户（vs Webflow 面向开发者）。

## 八、近年动态与公司状态判断

- 2019 入选 **腾讯 SaaS 加速器**首期成员
- 2020 与**猪八戒**联合发布"八戒云站"
- 2021.06 上线"商品评价"系统
- 2024 末–2025 初：**国际版上线 AI Site Builder + AI Logo Maker**
- 旗下独立 AI 产品 **标小智（logosc.cn）** 已生成超 251 万个 logo

**整体判断**：Strikingly 近年**信息密度明显下降，处于低调运营状态**，2024–2025 媒体新闻报道稀少，但仍在持续做产品迭代（AI 建站方向）和招聘。公司**产品上线次月即盈利**、累计融资不算多（1750 万美元），属于**自给自足型 SaaS**，而非烧钱扩张型。

## 十、面试要点提示

如果你是在准备 Strikingly（上线了）的面试，建议重点准备：

1. **能准确说出公司关键事实**：YC W2013、首个从 YC 毕业的中国团队、三位创始人姓名与背景、累计融资 1750 万美元、运营主体上海鲸科。
2. **理解产品差异化**：移动优先 + 单屏编辑 + 中国版微信小程序生态，是与 Wix/Squarespace 的核心区别。
3. **关注 AI 方向**：AI Site Builder 已在国际版上线，这是公司当前的产品重心，面试中可主动谈及对 AI 建站的看法。
4. **技术栈**：Rails + React + Hypernova（SSR）+ OpenResty/Lua + AWS/阿里云双云 —— CTO 郭达峰同时是阿里云 MVP 和 AWS Hero，技术栈面试时是加分点。
5. **CTO 背景**：郭达峰是 AWS Hero + 阿里云 MVP，技术影响力强，面试中如涉及云架构话题可深入。
