## 一、执行摘要

### 1.1 一句话判断

> **深圳乐城不是传统“企业管理咨询公司”，而更像 PARTYDAY 全国门店体系的总部/管理主体。PARTYDAY 是已经落地七家大型场馆的室内运动娱乐连锁，产品和扩张是真实的，商场合作方也能交叉验证；但它的财务、股权控制、单店模型和各法人之间的权责公开度较低。对求职者而言，这是一个“真实经营、仍在扩张、场景和技术有差异化，但重资产/重运营且组织透明度一般”的机会。建议继续面试，是否接 Offer 取决于具体业务线、签约主体、直属负责人、单店经济性及工时安排。**

### 1.4 最强正面信号

1. **不是概念项目。** 官网当前列有五城七店，单店面积 5,000–12,000 平方米；深圳大悦城、上海环球港及杭州项目的业主/合作方材料均能证明 PARTYDAY 的线下存在和项目体量。[S3][S7-S9]
2. **选址能力有含金量。** 门店进入万象城、环球港、万达、大悦城、荟聚及核心城市项目，说明团队至少具备商业地产谈判、设计施工、筹开和持续运营能力。
3. **产品不是普通电玩城。** 运动、多人社交、数字交互、IP、餐饮和团体活动可以覆盖家庭、年轻人、企业和学校，收入来源比单一售票更宽。[S2][S4-S6]
4. **场景与研发形成闭环的逻辑成立。** 线下门店可以测试设备、内容、计分与用户行为，再由初量科技将其中一部分做成智能运动设备；“嘭哒滑雪机”首次对外销售是早期产品化信号。[S11]
5. **门店复制已经跨城市发生。** 西安起步后扩展至深圳、上海、武汉、杭州，表明品牌已跨过单一城市/单店验证阶段。

### 1.5 核心风险

1. **大体量门店意味着高固定成本。** 约 5,000–12,000 平方米的租赁、装修、设备、能耗、维护、保险和人员成本都很重，淡旺季及客流波动会迅速影响利润。
2. **公开资料无法证明单店经济性。** 七店真实不等于七店盈利；没有坪效、客单价、复购、设备利用率、同店增长、EBITDA 或回本周期。
3. **法人和品牌口径混在一起。** 深圳乐城参保人数、JobUI 品牌规模、初量科技研发团队及各门店员工属于不同口径。候选人必须确认劳动合同、社保、奖金、期权和知识产权分别落在哪个主体。[S1][S12][S13]
4. **扩张可能先消耗现金。** 新店筹开通常先支付押金、装修和设备款，再逐步爬坡；2025–2026 年连续开店若缺少充足资金，会形成现金流和组织压力。
5. **科技标签强于公开技术证据。** 数字积分、计分和互动设备具有价值，但公开资料没有 API、架构、活跃用户、设备毛利、专利核心权利要求或第三方技术评测。
6. **安全和预付费是业务生命线。** 高空、攀爬、速度类项目、未成年人、团建及研学都可能产生伤害、消防、保险和退款风险；单店事故会伤害全国品牌。

### 2.2 为什么品牌 2018 年开始，而公司 2021 年才成立

2026 年深圳商报/读创的采访称，PARTYDAY 于 2018 年在西安开始探索，之后进入多座城市；工商聚合则显示深圳乐城成立于 2021 年。[S1][S11]

两者并不必然矛盾，合理解释是：

```text
2018 年左右：西安早期品牌/门店经营主体开始业务
        ↓
2021 年：深圳乐城与深圳初量科技成立，总部与研发能力向深圳集中
        ↓
2022 年以后：通过不同城市、不同门店法人继续扩张
        ↓
当前：PARTYDAY 品牌 + 总部管理主体 + 技术主体 + 各店运营主体
```

这种结构在连锁商业中常见，便于隔离租赁、用工、许可证和单店经营风险。但它也会带来候选人必须核验的问题：谁拥有商标和代码，谁收门票，谁承担租金和事故责任，谁给总部员工发工资。

## 三、创始人、管理层与治理

### 3.1 郝旻的公开角色

公开工商和行业活动材料可支持以下有限结论：

- 郝旻是深圳乐城法定代表人；[S1]
- 他曾以 PARTYDAY 创始人身份参加商业地产/文体消费行业论坛；
- 商业数据库将其关联到二十余家企业、担任多家企业法定代表人，但数量会随登记变化；
- 多个门店或关联主体出现其姓名，说明其对集团经营具有实质重要性。

本次没有找到足够可靠的教育、前雇主、创业履历、持股比例或个人融资记录。**不要把“法定代表人”“创始人”进一步包装成有某种名校、资本或大厂背景，除非面试方提供可验证材料。**

### 3.2 治理上的关键问题

连锁门店 + 技术公司 + IP 的组合，会产生五类治理边界：

| 边界 | 需要回答的问题 |
|---|---|
| 总部与门店 | 总部收管理费还是承担门店盈亏？店总对区域还是总部汇报？ |
| 运营与研发 | 初量科技是成本中心、利润中心还是独立对外销售主体？ |
| 境内与境外 | 香港主体是否持有品牌、融资或海外收入？境内员工权益与其有何关系？ |
| 品牌与 IP | PARTYDAY、PONDA、软件、游戏内容、设备专利分别由谁持有和授权？ |
| 决策权 | 新店选址、预算、内容更新和设备采购由谁拍板，失败责任如何承担？ |

若招聘方无法清楚说明岗位属于哪个法人、哪个预算和哪个汇报链，组织风险要明显上调。

### 4.2 产品到底卖什么

PARTYDAY 的核心不是一台设备或一款 App，而是一个大体量、长停留的线下体验组合：

| 客群 | 核心需求 | 可能产品/收入 |
|---|---|---|
| 年轻消费者 | 社交、运动、拍照、挑战与娱乐 | 门票、餐饮、周边、二次到店 |
| 家庭与儿童 | 室内活动、亲子陪伴、安全和便利 | 家庭票、生日派对、餐饮、IP 商品 |
| 企业客户 | 团队协作、活动组织、定制内容 | 团建方案、场地、餐饮、主持/赛事 [S5] |
| 学校/机构 | 研学、体育、科普与集体组织 | 研学课程、包场、课程/教练 [S6] |
| 商业地产 | 引流、延长停留、丰富业态 | 联营/租赁、联合营销、主题活动 |
| B 端场馆/文旅客户 | 互动设备、内容和运营方案 | 智能运动设备销售、软件/内容服务 [S11] |

官网将自身描述为“运动 + 娱乐 + 科技 + IP”的 Phygital（实体 + 数字）平台，并展示团建、研学、派对、数字体验、PONDA 家族 IP 等入口。[S2-S6]

### 4.3 官网用户数字如何解读

官网“关于我们”页展示了家庭用户 55 万+、年轻用户 80 万+、儿童用户 15 万+、微信公众号用户 100 万+、平均停留 4–6 小时、女性用户占比 65% 等数字。[S2]

这些数据可以视为公司有意识追踪用户结构的信号，但不能直接当作活跃用户或付费客户：

- 没有统计期间、去重规则和门店范围；
- 家庭、年轻、儿童和女性可以相互重叠；
- 微信“用户”可能是累计关注，不等于 MAU；
- 平均停留时间可能来自样本或调查，未说明样本量；
- 累计用户不能推出当年收入、复购和利润。

面试中应把问题从“你们有多少用户”改成：**最近 12 个月独立付费人次、同店客流、复购率、有效会员、获客成本和客单价分别是多少？**

### 4.4 扩张质量比门店数量更重要

从单城走向五城说明复制能力真实，但不同商圈的客群、租金和季节性差异很大。判断扩张是否健康，应看：

1. 老店是否仍保持正的同店增长；
2. 新店从试营业到盈亏平衡需要几个月；
3. 开店 CAPEX 中品牌自有资金、业主补贴和供应商账期各占多少；
4. 设备及内容有多少能复用，多少需要每店定制；
5. 项目故障率、排队时长、事故率和内容更新频次；
6. 关店、迁址、缩店及合同终止的历史是否完整披露。

## 五、商业模式与单店经济性

### 5.1 收入结构推演

公开资料没有收入拆分。根据产品结构，收入可能包括：

```text
门票/套票收入
  + 企业团建、学校研学、生日派对与包场
  + 餐饮、零售、IP 周边与积分增购
  + 品牌联名、活动及商业地产合作
  + 智能设备、软件或内容对外销售
  - 退款、优惠券、渠道佣金及预付票递延
```

其中“一票制”有利于降低用户决策成本，但也要求公司同时控制高峰排队、设备吞吐和低峰利用率。团建、研学和包场可以填补工作日低峰，通常是提升坪效的关键，而不仅是营销附属品。

### 5.2 成本结构

| 成本 | 业务特征 | 风险 |
|---|---|---|
| 租金/联营扣点 | 核心商场、大面积、长租期 | 固定成本高；谈判质量决定抗周期能力 |
| 装修与机电 | 主题化场景、承重、消防、空调、声光电 | 前期 CAPEX 大，迁址残值低 |
| 设备与内容 | 运动装置、传感器、屏幕、主机、游戏内容 | 折旧、故障、备件和快速过时 |
| 一线人员 | 安全引导、教练、收银、保洁、餐饮、维修 | 旺季排班与服务质量压力 |
| 能耗与物业 | 大空间、空调、灯光、设备连续运行 | 高客流未必自动带来高利润 |
| 保险与安全 | 公众责任、员工、未成年人及高风险项目 | 事故会带来赔偿、停业和品牌损失 |
| 获客与平台 | 短视频、团购、商场活动、渠道佣金 | 过度依赖折扣会损害客单价 |
| 总部与研发 | 内容更新、App/小程序、设备开发、品牌与选址 | 需要多店规模摊薄固定成本 |

### 5.3 不能跳过的单店公式

```text
单店收入 ≈ 到店付费人次 × 净票价
         + 团建/研学/派对收入
         + 餐饮与周边二消

单店贡献利润 ≈ 单店收入
             - 租金/扣点
             - 门店人员
             - 能耗物业
             - 设备维护与内容摊销
             - 渠道佣金、保险及日常运营

现金回本期 ≈ 开店净投入 ÷ 稳态年度经营现金流
```

真正重要的指标是**单位面积收入、单位工时产出、设备吞吐/开机率、同店增长和现金回本**。没有这些数据，“面积大”“项目多”“客流高”都可能只是成本和收入同时放大。

### 5.4 三种经营情景

| 情景 | 经营表现 | 对公司的影响 | 对员工的含义 |
|---|---|---|---|
| 乐观 | 新店快速爬坡、老店复购稳定、团建研学填平低峰、设备开始外售 | 总部成本被规模摊薄，选址/IP/数据形成飞轮 | 晋升和新项目机会多，奖金可见度提高 |
| 基准 | 门店总体在营，但不同城市差异大；增长主要来自新店 | 现金持续投入，管理复杂度上升 | 目标变化快，需要跨店支持，奖金依赖单店/集团口径 |
| 悲观 | 客流依赖开业热度和折扣，老店同店下滑，新店回本慢 | 租金和折旧压缩现金，可能缩店、延缓扩张或重组 | HC 冻结、成本控制、转岗和高运营压力上升 |

当前公开数据只能证明门店与产品存在，**不足以在三种情景中做确定选择**。

## 六、产品、技术与知识产权

### 6.1 数字体验有真实业务逻辑

官网数字体验页描述智慧园区系统、小程序/App、园区地图、项目数据、实时成绩、积分和礼品兑换等功能。[S4]

这些能力可以解决线下场馆的实际问题：

- 用地图和排队信息降低大型场馆的寻找成本；
- 用分数、排行榜和任务提高重复游玩；
- 将线下成绩沉淀到账号，形成跨店会员和复购；
- 用数据观察设备利用率、故障和内容受欢迎程度；
- 用积分和 IP 商品连接门票之外的收入。

如果执行良好，这套系统的价值不在“有一个 App”，而在于是否真正改变复购、吞吐、运维和二次消费。

### 6.2 初量科技与智能硬件

招聘资料把深圳初量科技有限公司描述为 PARTYDAY 的全栈研发和智能硬件支持主体；公开招聘曾包含 Unity/U3D、游戏开发、运维和硬件相关岗位。[S13][S15]

2026 年文博会报道中，公司代表介绍“嘭哒滑雪机”由硬件结构、传感交互、实时反馈和数字内容构成，并称这是设备首次对外出售，也是从“场景运营”走向“智能运动装备研发 + 业务”双轮驱动的一步。[S11]

这构成**产品化信号**，但还不能推出：

- 已实现规模化外售或稳定收入；
- 硬件、传感器、控制板和内容全部自研；
- 设备毛利、故障率、认证和售后体系成熟；
- 技术足以形成强专利壁垒；
- 公司已经具备通用 AI 模型或领先算法能力。

### 6.3 自研边界需要现场核验

门店页会使用“自研”“创研”等表述，部分 PONDA 项目称与国际多媒体团队 Moment Factory 合作。[S6] 本次没有找到 Moment Factory 侧对应项目公告。合作表述可能真实，但求职和合作判断应继续核验：

| 层次 | 应问的证据 |
|---|---|
| 游戏/内容 | Unity 工程、版本迭代、内容团队人数、上线和复用机制 |
| 场馆软件 | MAU、账号打通率、实时数据链路、离线容灾、支付和会员系统 |
| 硬件 | 自研 BOM 占比、传感器/控制板方案、量产数量、认证、故障率、备件 SLA |
| 算法/AI | 明确模型用途、训练/微调数据、线上指标、成本和人工兜底 |
| 第三方集成 | VR/XR 设备、显示和互动内容的供应商、授权期限及可替换性 |

### 6.4 IP 的价值和局限

商业数据库显示较多 PARTYDAY/PONDA 相关商标和一定数量的专利、著作权，说明品牌保护和内容登记并非空白。[S14] 原创 PONDA 家族也已在线下场馆和短视频内容中使用。[S2][S11]

不过，商标数量并不等于消费者心智，著作权登记也不等于软件技术领先。判断 IP 是否成为第二增长曲线，需要看：

- 周边收入和毛利占比；
- 非门票消费者的认知度；
- 内容播放、授权和联名收入；
- IP 是否能脱离 PARTYDAY 场馆独立获客；
- 版权链和员工/供应商创作合同是否完整。

## 七、融资、现金与财务透明度

### 7.1 没有可靠公开融资，不等于没有资金

本次未找到可由公司、投资机构或权威媒体交叉确认的 VC/PE 轮次、投资人、估值或融资金额。工商中的 500 万元注册资本和约 342 万元实缴资本是法人资本登记口径，**不是门店建设资金，也不是融资额。**[S1]

连锁扩张资金可能来自经营现金流、股东借款、关联公司、商业地产补贴、设备账期、银行/融资租赁或未公开股权资金。各来源对现金压力和员工稳定性的影响不同。

### 7.2 财务信息的关键空白

公开资料没有：

- 集团合并收入、毛利、净利润和经营现金流；
- 各店 GMV、净收入、EBITDA、同店增长和关店历史；
- 租金/联营扣点、免租期及业主装修补贴；
- 每平方米开店 CAPEX 和设备折旧年限；
- 预付票/会员余额、退款率及履约负债；
- 银行借款、股东借款、应付装修/设备款；
- 总部、门店和初量科技的关联交易；
- 海外项目预算、收入和汇率敞口。

没有上述信息，不能因为门店开在优质商场就推断公司现金充裕，也不能因为无公开融资就推断公司缺钱。

### 7.3 面试可接受的经营答案

招聘方未必能披露绝对收入，但一个成熟团队至少应能用区间或趋势回答：

- 老店最近四个季度同店收入是增长、持平还是下滑；
- 新店达到盈亏平衡和现金回本的大致周期；
- 工作日与周末、散客与团客的收入占比；
- 新店投资是总部出资、项目公司出资还是业主共投；
- 当前最重要的三个经营指标和过去一年的变化；
- 本岗位预算已批准到何时，是否依赖下一轮融资。

如果对方只能重复“七店”“百万用户”“出海”而回避趋势、口径和责任主体，应降低财务与治理评分。

## 八、竞争格局与护城河

### 8.1 竞争并不只来自同类品牌

| 竞争类型 | 典型替代 | PARTYDAY 的相对优势 | PARTYDAY 的压力 |
|---|---|---|---|
| 大型运动乐园 | Pokiddo、蹦床/空中运动乐园等 | 项目更综合、数字互动和主题设计更强 | 安全、设备和大面积成本同样高 |
| 亲子乐园 | MELAND、奈尔宝等 | 覆盖年轻人、企业团建和更强运动性 | 亲子品牌的家庭会员与服务标准更成熟 |
| 城市娱乐综合体 | INS 新乐园等 | 体育和主动参与属性更鲜明 | 夜经济、餐饮和娱乐内容更新竞争激烈 |
| 电玩城/密室/VR | 分布广、价格灵活、快速开店 | PARTYDAY 体验宽、停留长、多人社交 | 小店固定成本低，能更快换内容 |
| 体育馆/健身/户外 | 专业运动体验和长期训练 | PARTYDAY 门槛低、天气无关、娱乐性强 | 专业性和长期会员黏性可能较弱 |
| 商场其他业态 | 电影、餐饮、展览、零售 | 可成为主力店并显著延长停留 | 消费预算和时间仍在同一商场内竞争 |

### 8.2 可能形成的护城河

1. **优质点位和业主关系。** 大面积主力店的招商谈判、工程和履约记录不是新品牌可以快速复制的。
2. **跨城筹开与运营 SOP。** 招聘、培训、安全、维修、团建销售和内容更新的标准化，可能比单一设备更重要。
3. **内容、数据和硬件闭环。** 七店真实场景能持续验证项目，再把成功内容复制或外售。
4. **品牌与 IP。** PONDA 若能提高周边、社媒和复购，可能降低纯折扣获客依赖。
5. **大体量综合体验。** 项目组合、多人社交和长停留提高了单个小型竞品完整复制的难度。

### 8.3 护城河尚未被公开证明的部分

- 没有同店增长和复购数据证明品牌黏性；
- 没有设备外售订单和毛利证明 B 端产品化；
- 没有独立技术评测证明软件/硬件领先；
- 没有消费者调研证明 PONDA 已形成场馆外认知；
- 优质点位也可能伴随高租金和严格营业承诺；
- 大面积本身既是进入壁垒，也是退出成本。

**分析判断：** PARTYDAY 当前更可信的护城河是“点位获取 + 场馆设计筹开 + 内容组合 + 运营能力”，技术和 IP 是加分项，但公开证据还不足以把后两者视为独立强壁垒。

## 九、招聘、组织与工作体验

### 9.1 团队规模：20 人与 500–999 人为何同时出现

企查查/百度索引曾显示深圳乐城 2024 年参保人数约 20 人，较早 2023 年快照约 3 人；JobUI 把 PARTYDAY 公司规模标为 500–999 人。[S1][S12][S14]

最合理但仍需验证的解释是：

- 约 20 人是深圳乐城这一总部法人的参保口径；
- 初量科技和每家门店由不同法人雇佣员工；
- 500–999 人可能是招聘方填写的集团/品牌总人数；
- 招聘平台还可能包含兼职、实习或过期口径。

因此，不能说公司“只有 20 人”，也不能把“500–999 人”当作审计集团人数。候选人应直接问当前全职、门店、总部、研发和外包人数。

### 9.2 招聘信号

JobUI 在查询时展示约 37 个职位，并汇总历史公开职位：2023 年 32 个、2024 年 152 个、2025 年 281 个；2026 年职位需求显示同比下降约 74%。该平台的抓取、去重和“同比”口径不透明，且 2026 年尚未结束，不能据此断言公司裁员或停止扩张。[S12]

公开职位覆盖深圳、上海、西安、杭州、武汉，示例包括门店店长、饮品制作、直播运营、国内/海外销售、客户经理、技术和设计岗位。平台统计中技术约占 12%、设计约 11.4%，约 70.8% 的公开岗位落在月薪 1–3 万元，本科岗位平均约 2.06 万元。[S12]

这些是混合城市、职级和岗位的招聘样本，不是员工工资表。Offer 只能按具体城市、岗位、固定薪资、绩效和工时比较。

### 9.3 三类岗位其实是三家公司体验

| 岗位类型 | 机会 | 风险 | 面试核验重点 |
|---|---|---|---|
| 总部/战略/品牌/增长 | 接触多城扩张、商业地产、品牌和 P&L | 目标多、跨店协调、出差和数据口径复杂 | 决策权、预算、同店指标、出差频率、奖金口径 |
| 初量科技/研发 | 线下真实场景、Unity/IoT/互动硬件、快速验证 | 设备碎片化、现场故障、夜间/开业保障、外采集成多 | 自研比例、代码质量、on-call、发布流程、技术负责人 |
| 门店/运营/销售 | 客户反馈直接，晋升店长/区域路径清楚 | 周末节假日、晚班、体力和安全责任较重 | 排班、加班费/调休、奖金、事故责任、人员流失、店长权限 |

### 9.4 工时和文化：公开证据不足

本次没有找到足以代表全公司的可靠证据来确认：

- 总部是否普遍 996；
- 技术团队平均下班时间和 on-call 频率；
- 年终奖兑现率、调薪和晋升周期；
- 试用期淘汰、裁员或主动流失比例；
- 各门店劳动争议和员工满意度。

业务性质决定门店高峰集中于晚上、周末和节假日，新店筹开、设备故障和大型团建也可能产生临时保障。这是需要核验的**岗位固有暴露**，不是已经证明的违法加班结论。

### 9.5 适合与不适合的人

**更适合：**

- 希望积累连锁经营、商业地产、线下数字化或互动硬件经验；
- 能接受现场问题、跨部门协同和扩张期变化；
- 对用户体验、运动娱乐、内容和实体空间有兴趣；
- 能在数据不完美的情况下建立流程和指标。

**谨慎考虑：**

- 只想做纯互联网软件、拒绝现场支持或门店出差；
- 高度重视稳定双休且岗位直接支持门店；
- 需要清晰上市预期、标准期权或成熟财务披露；
- 无法接受业务优先级随开店、旺季和设备事故变化。

### 10.1 公开不利记录筛查

按准确公司名称和统一信用代码检索，本次在可访问公开渠道中**未识别出**深圳乐城本体的重大失信被执行、重大行政处罚、公开大规模欠薪或全国性闭店退款事件。商业数据库覆盖、更新和同名消歧均有限，这不构成“零风险证明”。

接 Offer 或合作前，应以以下系统复核：

- 国家企业信用信息公示系统：股东、年报、经营异常和行政处罚；
- 中国执行信息公开网：被执行人和失信记录；
- 中国裁判文书网/人民法院公告：诉讼和公告；
- 信用中国及各地市场监管、消防、文旅/体育部门；
- 各门店运营主体，而不只是深圳乐城总部。

### 10.2 业务最重要的合规面

| 风险 | 为什么重要 | 应核验材料/指标 |

商业数据库显示深圳乐城有约 3–4 项行政许可，但本次未取得许可证清单，不能由数量判断七家门店全部合规。[S14] 每个门店应由其运营主体持有适用许可。

### 10.3 安全不是后台职能，而是商业指标

对这类品牌，一次严重事故可能同时造成停业、赔偿、负面舆情、商场解约和团体客户流失。安全团队是否有独立停机权、事故是否进入店总绩效、设备故障是否能跨店追踪，比单纯“有安全制度”更有判断价值。

## 十二、面试反问清单

### 12.1 第一轮必须问的十二个问题

1. **这个岗位的劳动合同、工资、社保和个税分别由哪家公司承担？** 为什么不是深圳乐城，或为什么是某一家门店/初量科技？
2. **岗位属于总部、初量科技还是具体门店？** 它的成本中心、预算负责人和最终 KPI 分别是谁？
3. **当前集团的法律结构是什么？** 深圳乐城、越龙体育、初量科技、各城市门店和香港主体之间是什么股权及授权关系？
4. **过去 12 个月老店同店收入和客流是增长、持平还是下降？** 新店增长与同店增长各贡献多少？
5. **一家成熟门店的 EBITDA、现金回本期和坪效大致落在哪个区间？** 最好店与最慢店的差距为什么这么大？
6. **新店的租赁模式和 CAPEX 是什么？** 固定租金、流水扣点、免租期、业主补贴和公司自有投入各占多少？
7. **团建、研学、散客、餐饮/周边各占收入多少？** 工作日低峰主要靠什么填充？
8. **2025–2026 年连续扩张的资金来自哪里？** 当前现金可覆盖多少个月的总部和已签约门店投入？
9. **初量科技的自研边界是什么？** 软件、游戏内容、控制系统、硬件结构和第三方设备各占多大比例？
10. **数字系统最近 30 天的有效用户、绑定率、复购转化和设备数据覆盖率是多少？** 哪个指标证明它不是营销功能？
11. **团队真实工时如何？** 最近一个月几点下班、周末保障几次、节假日如何排班，加班费/调休和 on-call 补偿如何执行？
12. **为什么现在开放这个 HC？** 是新增、离职替补还是组织调整？前任在岗多久，试用期三个月如何判断成功？

### 12.2 技术岗位追加问题

1. 当前 Unity/U3D、后端、客户端、嵌入式、硬件和现场运维各有多少全职人员？
2. 一套项目从研发到七店上线的发布流程是什么？是否有灰度、远程回滚、离线容灾和自动监控？
3. 线上设备开机率、故障 MTBF、维修 MTTR 和重大故障数是多少？
4. 夜间、周末和新店筹开的现场支持由谁轮值？最近三个月实际发生几次？
5. 自研代码和外购 SDK/设备的比例如何？最难替换的三个供应商是谁？
6. 用户账号、成绩、影像和未成年人信息存在哪里，门店之间如何隔离和授权？
7. 研发考核更看版本数、设备稳定性、用户复购还是设备外售收入？
8. “AI”在当前生产系统中具体解决什么问题？有无模型指标、成本、人工兜底和事故责任边界？

### 12.3 运营/店长岗位追加问题

1. 本店编制、全职/兼职比例、月流失率和实际缺口是多少？
2. 每班工时、最晚下班、周末/法定节假日排班及加班费如何计算？
3. 店长能决定多少人员、营销、维修和退款预算？
4. 奖金按销售、利润、好评、安全还是集团目标计算？哪些指标一票否决？
5. 最近一年发生过多少起需要报保险的顾客伤害，如何复盘？
6. 设备停机、排队和客诉的 SLA 是什么？总部支持是否及时？
7. 团建/研学销售由门店还是总部负责，收入和佣金如何归属？
8. 若门店迁址、缩店或业主合同变化，员工怎么安置？

### 12.4 战略/产品/增长岗位追加问题

1. 当前最重要的北极星指标是收入、同店增长、复购、坪效还是开店数？
2. 官网用户数据的时间范围、去重和付费口径是什么？
3. 海外战略是输出设备、品牌加盟、直营场馆还是合资？已经签约和已确认收入分别是多少？
4. PONDA 的场馆外收入、内容播放和非门店粉丝指标如何？
5. 新店选址模型如何评估商圈、租金、客流转化、竞品和回本？谁有否决权？
6. 如果老店同店下滑与新店开业冲突，资源优先级如何决定？

### 12.5 对回答质量的判断

**绿灯回答：** 给出明确法人、汇报人、时间区间、指标定义和趋势；能承认表现较弱的门店或项目，并说明改进动作。

**黄灯回答：** 只能给大致方向，但愿意在终面或 Offer 前补充组织图、合同样本、KPI 和排班规则。

**红灯回答：** 用“商业机密”回避所有趋势；把商场客流说成门店客流；把注册资本说成融资；把累计用户说成活跃付费用户；无法说明签约主体；口头承诺双休/奖金/期权但拒绝写入材料。

### 13.2 推荐做的线下验证

对于线下消费公司，亲自去店比只看新闻更有效：

1. 工作日和周末各看一次真实客流；
2. 观察购票转化、排队、设备停机、清洁和员工数量；
3. 体验小程序、计分、积分和跨项目账号是否顺畅；
4. 询问退款、储物、受伤处理和未成年人规则；
5. 看多少项目是独特内容，多少是常见采购设备；
6. 观察员工是否持续救火、是否有足够维修和安全人员。

这不能替代财务尽调，但能快速检验官网叙事与运营现场是否一致。

## 十四、最终结论

深圳乐城背后的 PARTYDAY 是一项**已经被线下资产、商场合作和跨城门店证明存在的真实业务**。它最值得肯定的不是“科技公司”标签，而是能把大面积商业空间、运动娱乐内容、数字互动和运营体系落到七家场馆，并继续尝试把设备与 IP 产品化。

它最大的未知也同样明确：**七店是否有健康的同店增长和现金回本，资金从哪里来，多法人之间如何分配收入、成本和员工权益。** 官网累计用户、招聘平台人数及媒体中的 AI/出海表述，都不能回答这些问题。

对求职者的最终建议是：

- **总部、技术核心或有明确 P&L 的岗位：值得重点面试。** 能获得连锁扩张、线下数字化、互动硬件和商业地产的复合经验。
- **门店岗位：可考虑，但必须把排班、奖金、安全责任和晋升路径核验到具体门店。**
- **仅靠海外、AI、IP 或设备外售故事支撑的新岗位：审慎。** 需要实际客户、预算和负责人证明。
- **任何无法说明劳动合同主体、工资社保主体和汇报线的 Offer：不建议接受。**

综合而言，这不是“信息一查就明显有问题”的公司，也不是财务和治理高度透明的成熟连锁。最合理的策略是：**继续面试，用单店经济性、岗位归属、实际工时和现金预算四组问题决定是否接 Offer。**
